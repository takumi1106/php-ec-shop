# PHP EC Shop

PHP・MySQLを使用して制作したECサイトです。
授業課題をベースに、商品検索やカート、お気に入り、購入履歴などの機能を実装しました。

## 主な機能

- 商品一覧・商品詳細
- 商品検索
- 会員登録・ログイン
- カート機能
- お気に入り機能
- 商品購入
- 購入履歴
- 商品ランキング
- 在庫管理
- クーポン機能

## 使用技術

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## 制作ツール

- VS Code
- MAMP
- phpMyAdmin
- 生成AI（補助的に使用）
