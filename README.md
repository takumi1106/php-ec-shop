# PHP EC SHOP

PHP・MySQLを使用して制作したECサイトです。

## 作品概要

PHP・MySQLの授業課題として制作したECサイトです。
商品検索やカート、お気に入り、購入履歴など、ECサイトに必要な基本機能を実装しました。
また、在庫管理や商品ランキング、クーポン機能なども追加しています。

## サイトURL

## 作成技術

HTML / CSS / JavaScript / PHP / MySQL

## 制作ツール

VS Code / MAMP / phpMyAdmin / 生成AI（補助的に使用）
